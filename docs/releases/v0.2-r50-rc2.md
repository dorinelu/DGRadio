# DG Radio v0.2-r50 RC2 — Update Manager Introduced

**Internet Radio, the Winamp Way!**

Release Candidate 2 brings the first built-in **Update Manager**, expanded Spanish radio stations and an improved Settings screen.

## Highlights

- **Built-in Update Manager:** checks GitHub for updates automatically at startup (if enabled) or manually via **Settings → YELLOW**.
- Shows the available version and changelog, and asks before downloading and installing the IPK.
- HTTPS download with SHA-256 validation; GUI restart requires confirmation.
- Settings now shows **RED Cancel**, **GREEN Save** and **YELLOW Check for Updates**, plus detected front-panel information.
- Seven additional Spanish stations are present in the playlist: Europa FM España, HIT FM, Cadena Dial, Radiolé, Onda Cero, Flaix FM and Ibiza Global Radio. Station/stream availability can vary.
- Footer no longer repeats the plugin version; it remains in the main title bar.
- Preserves Winamp-inspired skin, weather, station logo cache and album artwork.

## Important: one-time manual installation

**RC1 and older installations do not include the Update Manager.** Install this RC2 IPK manually once. From this version onward, future published releases can be detected, downloaded and installed within DG Radio.

**Package:** `enigma2-plugin-extensions-dgradio_0.2-r50_all.ipk`

After installation, restart the Enigma2 GUI, then open **DG Radio → Settings → YELLOW (Check for Updates)**.

## Compatibility and feedback

Developed and tested on Vu+ Solo 4K with OpenATV and OpenBH. MP3/AAC/AAC+ playback depends on receiver image and installed decoders. This is a Release Candidate; feedback and stream corrections are welcome.
