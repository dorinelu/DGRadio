# DG Radio v0.2-r45 RC1

**Internet Radio, the Winamp Way!**

This is the first public Release Candidate of DG Radio, a Winamp Classic-inspired internet radio player for Enigma2 receivers.

## Features
- Multi-country internet radio station lists
- MP3, AAC and AAC+ playback, depending on the Enigma2 image and multimedia components
- Now Playing artist/title metadata and album artwork when available
- Radio station logos with persistent local caching
- Weather information
- Classic Winamp-inspired interface and transport controls

## Improvements in this release
- New DG Radio branding and proportional Plugin Browser icon
- Optimized 345 × 270 px fallback artwork
- Wider playlist and improved right-side alignment
- Simplified copyright footer
- Persistent station logo cache and fallback logic
- Reduced package size (~622 KB)

## Compatibility
Developed and tested on Vu+ Solo 4K with OpenATV and OpenBH. Feedback from other Enigma2 images and devices is welcome.

## Installation
Download `enigma2-plugin-extensions-dgradio_0.2-r45_all.ipk` from this release and install using your Enigma2 image's local package installer, then restart the Enigma2 GUI.

## Feedback
Please report receiver model, Enigma2 image/version and steps to reproduce any issue. Suggestions for new radio stations and country playlists are welcome.
