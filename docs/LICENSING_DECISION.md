# Licensing decision — DG Radio v0.2-r50

On 17 November 2026 the project author expressly approved releasing the original r50 code **and original graphics** under `GPL-2.0-or-later`.

The GPL-2.0 full text is at `/LICENSE`. A GPL-2.0-or-later grant means the recipient may use GPL version 2 or any later GPL version published by the FSF; it is not a claim that GPL version 3 applies exclusively.

The user also attested that the project and graphics were developed from scratch across approximately fifty revisions, without incorporating Winamp-licensed material. This is an author statement, not independent forensic verification.

**Open issue:** `DGRadioMonoCondensed.ttf` must be checked for embedded font metadata and any upstream license; only original font work may be licensed by the author. Third-party radio logos and fetched artwork are excluded.

The r50 source archive extracted from the IPK should be committed before tagging a reproducible release or claiming that HD Satelit can build from this repository.
