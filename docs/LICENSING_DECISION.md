# Licensing decision — DG Radio v0.2-r50

On 17 November 2026, the project author approved `GPL-2.0-or-later` licensing for the **original code and original graphics** of DG Radio r50.

The author states the project and its interface graphics were created independently across approximately 50 revisions and do not include Winamp-licensed assets. This is an author attestation, not an independent forensic guarantee.

## Verified third-party exception

The file `DGRadioMonoCondensed.ttf` is a renamed **DejaVu Sans Condensed** font, not original artwork. Its embedded TrueType name metadata credits Bitstream (2003), Tavmjong Bah (2006), and the DejaVu fonts team and includes a font-license description. Retain its original font licensing and copyright notices separately. The GPL grant for original DG Radio assets does not override these third-party font rights.

The r50 source tree still needs to be committed and verified before HD Satelit can build reproducibly.
